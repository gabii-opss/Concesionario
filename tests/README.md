# Pruebas

Esta carpeta contendrá la documentación y los casos de prueba del proyecto.

Por ahora el programa se verifica manualmente: se abre el proyecto en NetBeans, se ejecuta la clase `Main` y se comprueba que el menú y sus opciones funcionen.

En las próximas entregas se agregarán el plan de pruebas, los casos de prueba y las evidencias de ejecución.
